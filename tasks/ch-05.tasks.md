### Step 5.6 — Generate an idempotent SQL migration script

**Goal**: Produce a production-safe, idempotent SQL script for `InitialCreate`.
**Files affected**:
- `starter-solution/migrations/InitialCreate.sql` (new)
**Chapter section**: Ch.05 §5.4
**Verify**:
```bash
dotnet ef migrations script --project starter-solution/src/EduPlatform.Persistence --startup-project starter-solution/src/EduPlatform.Web --output starter-solution/migrations/InitialCreate.sql --idempotent
```

**Understand before continuing**: Why do production pipelines prefer an idempotent migration script instead of running `database update` directly on every container?
