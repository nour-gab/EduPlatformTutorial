## Notes

- Chapter 6 is the densest chapter so far. If a step's `dotnet build`
  fails with `CS0246: 'IRepository<>' could not be found`, you
  skipped Ch.06 §6.6 — go back and add the interfaces.
- The `Result<T>` type comes from the `Ardalis.Result` NuGet package
  referenced in Ch.05 §5.0. If the package isn't restoring, run
  `dotnet restore src/EduPlatform.Application/`.
- This chapter introduces 12 new files. Don't be tempted to "do them
  all in one go" — the whole point of CQRS is that each handler is
  small and independently testable. One at a time lets you see the
  pattern emerge.
- If you get stuck on the open-generic behavior registration
  (`cfg.AddOpenBehavior(typeof(LoggingBehavior<,>))`), check Ch.06
  §6.5.5 for the exact syntax. The `<,>` (comma, no type args) is
  the open-generic marker — easy to typo.
