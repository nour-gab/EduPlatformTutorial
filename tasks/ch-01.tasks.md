# Chapter 1 — Project Overview & Architecture Map — Task List

> Read `chapters/01-overview.md` fully before starting. This chapter

> to verify the environment works and to internalize the architecture
> map before chapter 2 starts scaffolding projects.

## Steps

### Step 1.1 — Verify environment

**Goal**: Confirm .NET 8 SDK is installed and the starter solution restores.
**Files affected**: (none — read-only)
**Chapter section**: Ch.01 §1.7 (Setting up your machine)
**Verify**:
```bash
dotnet --version          # reports 8.0.x
cd starter-solution
dotnet restore
# Output: "Restore completed in Ns" with no errors
```
**Understand before continuing**: Why does this tutorial target .NET 8
LTS specifically, not .NET 9 STS? (See Ch.01 §1.2, table row 1.)

### Step 1.2 — Build the starter solution

**Goal**: Confirm all 5 starter projects compile out of the box.
**Files affected**: (none — read-only)
**Chapter section**: Ch.01 §1.7 (continued); cross-ref Ch.02 §2.5
**Verify**:
```bash
cd starter-solution
dotnet build
# Output: "Build succeeded. 0 Error(s)" with warnings allowed
```
**Understand before continuing**: Which project has `Sdk="Microsoft.NET.Sdk.Web"`
and why is that the only one? (See Ch.02 §2.5.5.)

### Step 1.3 — Try to break the Dependency Rule

**Goal**: Prove the Dependency Rule is enforced at compile time by
deliberately violating it.
**Files affected**:
- `src/EduPlatform.Domain/Common/BaseEntity.cs` (edit — add a forbidden using)
**Chapter section**: Ch.02 §2.2 (The Dependency Rule, mechanically)
**Verify**:
```bash
# After adding `using Microsoft.EntityFrameworkCore;` to BaseEntity.cs:
dotnet build src/EduPlatform.Domain/EduPlatform.Domain.csproj
# Expected: CS0234 error: 'EntityFrameworkCore' does not exist in namespace 'Microsoft'
```
Then **revert** the change:
```bash
git checkout -- src/EduPlatform.Domain/Common/BaseEntity.cs
dotnet build
# Expected: build succeeds again
```
**Understand before continuing**: Why is compile-time enforcement of
architectural rules more valuable than documentation or code review?
(See Ch.02 §2.2, "Architect's note — Compile-time enforcement > documentation.")

### Step 1.4 — Read the architecture diagram

**Goal**: Open `diagrams/architecture.mmd` and recognize the 5-project
dependency graph.
**Files affected**: (none — read-only)
**Chapter section**: Ch.01 §1.3 + Ch.02 §2.3
**Verify**: (subjective) Open the file; the student can name which
projects `Web` references and which projects `Domain` references.
**Understand before continuing**: Why do `Persistence` and
`Infrastructure` both depend on `Application` but not on each other?
(See Ch.01 §1.3, "Architect's note — Two outer rings instead of one.")

### Step 1.5 — Read the chapter's "Further reading" list

**Goal**: Bookmark the 5 books/articles referenced in Ch.01 §1.9 for
future deep dives.
**Files affected**: (none — read-only)
**Chapter section**: Ch.01 §1.9
**Verify**: (subjective) The student has at least 3 of the 5
references open in browser tabs or bookmarks.
**Understand before continuing**: Of the 5 references, which one
would you read first if you wanted a deeper treatment of the
Dependency Rule, and why? (No wrong answer — but articulate your
reasoning.)

### Step 1.6 — Hands-on exercise: start your `notes.md`

**Goal**: Create `notes.md` at the root of your local tutorial folder
per Ch.01 §1.8. This is your learning journal.
**Files affected**:

  preference; suggested: gitignore since it's personal)

**Verify**:

**Understand before continuing**: What surprised you most about the
architecture choice? What's one question you'd ask the architect if

## Notes

- Chapter 1 is intentionally light on code. The architectural
  concepts (the 4-agent pipeline, the 5-ring dependency graph, the
  tech stack rationale) need to be internalized before chapter 2
  starts adding files. Don't rush to chapter 2 — re-read sections
  that confuse you.
- If your `dotnet build` failed, the most likely cause is missing
  .NET 8 SDK. Install from <https://dotnet.microsoft.com/download/dotnet/8.0>
  and re-run.
- If you're on Windows and SQL Server LocalDB isn't installed,
  install from SQL Server Express (includes LocalDB). You don't
  need it for chapter 1, but you'll need it starting chapter 5.
