### Step 1.2 — Map the product scope

**Goal**: Identify the six included modules and the deliberately excluded features that keep the LMS tutorial focused.
**Files affected**: (none — read-only)
**Chapter section**: Ch.01 §1.1
**Verify**:
```bash
rg -n "Course catalog|Authentication & roles|Enrollment workflow|Instructor portal|Reviews & ratings|Admin dashboard|Payment processing|Video transcoding|Real-time chat|Multi-tenant SaaS" chapters/01-overview.md
```
The command must find all six included modules and all four excluded features.
**Understand before continuing**: How does excluding payments, video transcoding, chat, and multi-tenancy protect the tutorial's core learning goals?

### Step 1.3 — Explain the technology choices

**Goal**: Connect each major technology choice to its stated reason and rejected alternative.
**Files affected**: (none — read-only)
**Chapter section**: Ch.01 §1.2
**Verify**:
```bash
rg -n "Runtime|UI|App architecture|Persistence|Auth|Logging|Validation|Caching|Tests|Blazor|Dapper|JWT" chapters/01-overview.md
```
The command must locate the complete technology decision table and its MVC-versus-Blazor architect's note.
**Understand before continuing**: Why is server-rendered MVC a better fit than Blazor for this content-first catalog tutorial?

### Step 1.4 — Trace the five architectural rings

**Goal**: Trace the allowed dependency direction from Domain outward through Application, Persistence and Infrastructure, to Web.
**Files affected**: (none — read-only)
**Chapter section**: Ch.01 §1.3
**Verify**:
```bash

rg -n "Domain|Application|Persistence|Infrastructure|Web" diagrams/architecture.mmd chapters/01-overview.md
```
Both commands must succeed, and the diagram must contain all five projects.
**Understand before continuing**: Why do Persistence and Infrastructure both depend on Application but not on each other?

### Step 1.5 — Follow the CQRS request flow and tutorial method

**Goal**: Explain how a browser request travels through a thin MVC controller, MediatR behaviors, an Application handler, Persistence, and a Razor view, then relate that flow to the chapter sequence.
**Files affected**: (none — read-only)

The command must locate each major stage of the end-to-end flow.
**Understand before continuing**: What two responsibilities move out of controllers when CQRS and pipeline behaviors are used here?
